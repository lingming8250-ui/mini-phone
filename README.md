# 小手机

液态玻璃风 AI 聊天 + 背单词，PWA 可添加到主屏。

## 功能
- 微信风格多角色 AI 聊天（独立会话、通讯录、朋友圈、钱包、主角人设）
- 单聊增强：正在输入中、重新生成、多条回复、批量发送、表情包 URL
- 背单词（四选一 + 错词本 + 自定义词库）
- 世界书 / 记忆 / 数据备份
- PWA 支持，可安装到手机主屏

## 部署心法（重要）
改代码推 GitHub，Zeabur 会自动部署，不用手动点服务器。

流程：改代码 → push 到 main → Zeabur 自动重新部署 → 刷新网页即可。

## 部署
推送到 GitHub 后，用 Zeabur 连接本仓库部署为静态站点（根目录有 index.html，自动识别）。

## 本地运行
直接打开 index.html，或 `npx serve .` 起本地服务器。
